# Rung-6 frontier slate and rung-7 workshop template

**Draft source preparation, 2026-08-13.** Each entry has a source-audit date, a mandatory pre-publication recheck, bounded falsifiable work, and an external-expert gate. None reports a live problem status or a resolution.

| Dossier | Bounded first contribution | Explicit non-claim |
|---|---|---|
| Kaplansky zero-divisor | Reproduce one fixed group-ring product with stated ring and presentation. | A unit-conjecture result is not silently a zero-divisor result. |
| Union-closed | Verify one finite family and one exact frequency bound. | A constant lower bound is not the one-half conclusion. |
| Erdős–Straus | Produce exact decompositions over one declared finite range. | A range certificate is not a universal proof. |
| Three cubes | Verify one fixed-​k integer witness or bounded search. | A search boundary is not a nonexistence theorem. |
| Sendov | Audit one degree-indexed source claim or polynomial family. | A claimed proof is not a settled result without external review. |
| Lonely runner | Check one exact velocity-tuple certificate. | One tuple does not establish a k-range theorem. |
| BB(6) | Replay one model-fixed machine to one lower-bound checkpoint. | A lower bound is not an exact value. |
| Quantum channel additivity | Certify one functional-specific finite-channel inequality. | “Additivity” has no meaning without its named functional. |
| Navier–Stokes | Check one finite Galerkin energy identity. | A finite simulation cannot settle global regularity. |

## Rung-7 new-theory workshop template

A new-theory workshop must name an exact construction, explicit predictions, consistency checks, a distinction from established theory, a falsifier, one bounded first test, safety/dual-use notes, and an external-expert review plan. Completing the template does not establish novelty, correctness, physical relevance, or compatibility with established theory; those are separate claims requiring their own evidence and review.
